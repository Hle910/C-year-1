Pairs
Input a number(doesn't matter negative or positive)
Input 10 more numbers(Program will tell which number you are on, positive or negative does not matter)
Program will calculate all pairs of numbers when squared and added together equal to the square of the first number you inputted.
Program will eliminate any duplicate numbers and does not include the same pair even if ordered different.

Primes
Input a number
Program will list all prime factors of input ordering smallest prime to largest
Repeat a second time

Fibonacci
Input a number
Program will list the first terms(least to greatest) of the Fibonacci sequence until it reaches nth term, the number you input
Program will add all numbers together and give you the sum

Matrix Pairs
Input a number for the rows
Input a number for the columns
Input numbers until you fill all rows and columns (Total amount= Rows X Columns)
Repeat for second matrix
You will be told if the matrix are mirrors of each other
Matrices are mirrors of each other if Matrix 2 is read right to left and Matrix 1 is left to right

Least To Greatest
Input 10 intergers(Program will tell you what number you are on, negative or positive does not matter)
You will receive sorted list least to greatest

Matrix Add
Enter number of rows and columns
Input values for matrix 1 until you fill all columns and rows (Total Amount= Rows X Columns)
Repeat for matrix 2
Program will inform the sum of both matrices (Matrix addition is the number of the same row and column added together)

Insert
Enter an integer for size of the array (Positive values)
Enter numbers(Program will tell you what number you are on)
Enter additional value
Program will sort least to greatest and return values

Factorial
Enter an integer(Positive or negative does not matter)
Enter another integer
You will receive the factorial
Factorial= (1st number)!/|(1st number-2nd number)|!

Armstrong
Enter a number(Positive only)
Program will indicate if it is an Armstrong number.
