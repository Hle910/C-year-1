1: Enter the number of students you would like to record (max 15, min 5);
2: Input first name, last name, and score of student.
	You are given 45 characters to input their record:
		first name cannot exceed 20 characters
		last name cannot exceed 20 characters
		score must be in between 0-100
3: A menu will drop down for options:
	0 is to quit program
	1 is to print all records from how they were entered
	2 is to print all records of students based on first name
		Input a first name to search, all students with same name will be printed
			INPUT IS CASE SENSITIVE
	3 is to print all recordss of students based on last name
		Input a last name to search, all students with same name will be printed
			INPUT IS CASE SENSITIVE
	4 is to sort records by score
		program will print out student records based on lowest to highest score
	5 is to sort records by last name
		program will print out student records based on alphabetical order
	6 is to find students with the maximum score
	7 is to find students with the minium score
