Enter a number between 5 and 15 to add records
Enter the number of records asked
Enter one of the numbers to use the following functions:
1- Print records: Prints records of all students added
2- Add record: Adds a student to the records
3- Delete records: Removes a student from the records
4- Search by last name: Reports all students based on the last named asked
5- Sort by score: Orders all students based on highest score
6- Sort by last name: Orders all students based on alphabetical order from their last name
7- Find median: Takes the median score of all students
