Insert Least to Greatest
When asked to input numbers in ascending order, enter a total of 13 numbers from least to greatest.
When asked to input numbers in ascending order a second time, enter a total of 5 numbers from least to greatest.
Program will print the sorted list.

Pair Add
Enter a target value, must be a positive integer
Enter array values, must be positive integers
Program will print which pairs in the array add together to be equal to target value.
Pairs will only print once, having more than 2 of the same integer will not print again.

Add Reverse
Enter any positive integer, program returns the number in reversed with the sum of the two.

Repeating Characters
Enter any phrase that does not have a total over 10 characters, spaces are included.
Program will return the amount of different characters repeated and which one.

String Reverse
Enter a sentence that does not exceed 50 characters, spaces included.
Program will print the sentence in reverse.

Power of 2
Enter any positive integer.
Program prints out n terms, where n is the integer inputted.
The equation for each term is the (previous term x previous term)+1, where 0 is the previous term before 1, and 1 is the first term.

String Sort
Enter 4 letters in any order, do not exceed or go below 4 letters.
Repeat 4 more times
Program will list the grouped letters alphabetically.

Prime Pairs
Enter any positive integer
Program will print all pairs of prime numbers that equal the input number once.

alphabet
Enter anything that does not exceed 20 characters, spaces included.
Program returns only alphabetical letters, no spaces.

MMM
Enter a value for the amount of hours you spend playing each day of the week.
Repeat for the amount of hours you spend studying each day of the week.
Program will respond how well you play games/study based on if which mean, median, and mode are higher.

Second
Enter a positive integer for number of terms
Enter any integer, negative or positive, until you reach maximum number of terms.
Program will indicate the second largest and second smallest number.

OddEven
Enter an integer for number of terms you will input.
Enter any positive integer.
Program will print out the even and odd integers.
