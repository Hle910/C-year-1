Instructions:
Enter a minimum of 5 records, containing ID, First name, Last name, Score, and Zip code.
	No duplicate IDs allowed
	Press enter to save each information
	ID must be an integer within 1000-1100
	First name and Last name have a maximum length of 20 characters
	Score can be a double, but only prints to the tenth place
	Zip code is an integer
User will be prompted the following options:
1: Print records
	Print all student records from through inorder traversal.
2: Add record
	works the exact same as adding the first 5 records
3: Delete record(s)
	Enter a last name, program will scan any records with the same last name and delete it
4: Search by ZIP code
	Enter a zip code, program scans any records that match and prints
5: Search by score range
	Enter a minimum score, then enter a maximum score, it will print all records with scores within the range(including the minimum/maximum)
6: Find median score
	Prints median score as a double only to the tenth place, then prints all students above the median.
0: Exit program
