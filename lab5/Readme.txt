Program by default will ask you to input 5 records, each record holds firstname, lastname, score, and ZIP code
Press enter after each input.
Note: There are a maximum of 20 characters for last name and first name
Score can be a double, but will automatically round up to the tenths place when printing
ZIP code is an integer
Menu will prompt choices:
0= Stop program
1= Print all records that are saved
2= Add a new record, works the same way when adding the 5 first records
3= Delete a record, enter a last name and it will delete all records with that last name
4= Search by ZIP code, prints all students with the exact same ZIP code entered
5= Search by score range, input a minimum and maximum score, cannot be a double, prints students within score range
6= Find median score, automatically determines the median score and all students that are above that score
